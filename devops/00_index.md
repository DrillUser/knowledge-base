# Банк вопросов — DevOps/SRE (junior+/middle)

> Рабочий индекс. Каждый крупный блок — отдельный файл (грузим только нужное). Карточка: вопрос → ответ за 30–60 сек → глубокий ответ → follow-ups → статус. В конце каждого блока — раздел **«Практика»**: лабораторные задания, которые нужно реально выполнить руками, чтобы закрепить материал.

## Легенда статусов
- 🔴 не знаю / поплыву
- 🟡 учу, отвечу базово
- 🟢 готов, вытяну с уточнениями

Статус проставляется на уровне каждой карточки (поле **Статус** в конце) — обновляй его по факту, когда реально прогнал тему вслух или руками.

## Порядок изучения — от базы к продвинутому
Linux → данные → стриминг/наблюдаемость → контейнеры → Kubernetes → Istio/GitOps → отказоустойчивость (сквозной синтез) → сети/прокси. Каждый слой ложится на предыдущий: контейнеры держатся на namespaces/cgroups Linux, Kubernetes — на контейнерах, Istio — на Kubernetes, GitOps — на декларативности Kubernetes, блок HA связывает Patroni/Kafka/etcd/Istio в одну сквозную тему (кворум, split-brain, failover, RTO/RPO).

## Формат карточки
Вопрос → **Суть** (одна фраза на понимание) → **За 30–60 сек** (что сказать сразу) → **Глубокий ответ** (механика, нюансы, связи с другими карточками) → **Follow-ups** (дерево уточняющих вопросов) → иногда «Руками» (как сформулировать через реальный опыт) и «Подводные камни» → **Статус**.

## Практика
Каждый блок заканчивается разделом «Практика» — лабораторными заданиями возрастающей сложности. Смысл не в пересказе карточек, а в работающей системе: разверни, сломай, почини, замерь. Каждое задание отсылает к карточкам, которые оно закрепляет, а где уместно — к разным бизнес-сценариям (например, «нужен RPO=0 для финансовых транзакций» против «async-репликация достаточна для аналитики»), которые меняют правильный технический выбор.

## Известные пробелы в покрытии (бэклог тем)
- **Linux:** eBPF/perf/bpftrace (продвинутый трейсинг); `/proc` и `/sys` как интерфейсы ядра; типы ФС (ext4/xfs, журналирование); users/sudo/PAM; nice/renice/taskset (CPU affinity); NTP/время; rsyslog/logrotate.
- **Отдельным блоком (пока не заведён):** Bash + текстовая обработка (awk/sed/grep) — программирование/автоматизация для DevOps.
